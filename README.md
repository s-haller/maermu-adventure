# Märmu

A point-and-click adventure about a marmot, a letter, and a wiki that lives in the Alps.

## Play

```sh
npm install
npm run dev
```

Open http://localhost:5173 and choose a chapter.

## How to play

The controls follow *Beneath a Steel Sky*. There is no verb menu. The line under the picture names what a left click will do.

- **Left click** something in the scene to interact with it. That opens a door, talks to someone, picks an object up, or walks Märmu across the ground.
- **Drag** an item from the pack with the left button and drop it on something in the scene to use the two together. While you drag, the line reads `Use cheese on Herr Wolke`. Let go away from a target and the item stays in the pack.
- **Right click** to examine whatever is under the cursor, in the scene or in the pack.

A left click on the letter or the notebook reads it. A right click examines it.

`Esc` opens the chapter menu. `D` draws the hotspot boxes.
